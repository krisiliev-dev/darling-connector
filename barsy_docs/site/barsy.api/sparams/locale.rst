Локализация / Език на отговора
===============================

barsy дава възможност за мултиезична работа, която включва:

 * Превод на всики потребителски данни (като имена на `артикули </barsy.help/210-dictionary/article.html>`__, описание на `артикули </barsy.help/210-dictionary/article.html>`__, имена на `категории </barsy.help/210-dictionary/category.html>`__ и т.н.)
 * Превод на всички `съобщения </barsy.help/210-dictionary/message.html>`__, върнати от системата
 
По подразбиране - системата работи на локализацията, която е зададена като системна
Ако искате да смените езика само за текущата заявка, трябва да подадете допълнител параметър lang_id=xx_XX.
Параметърът се подава като чат от URL адрес на заявката.

Пример

/endpoints/json/?lang_id=en_US
