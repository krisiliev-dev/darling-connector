Защо заявката ми към Barsy API завършва с изтекло време?
========================================================

Отговор
----------------------
Всеки метод в barsy API има заделено процесорно време за изпълнение. Това е направено за да се предпази конкретната ситема от единично претоварване или теглене на неразумен обем информация.
По подразбиране това време е 30 секунди. За някой методи времето е увеличено.

Всяка инсталация разполага с различна хардуерна мощност и от това пряко зависи колко "работа" може да свърши в рамките на отделеното време.

* При локалните инсталации - това зависи от цялостната хардуерна конфигурация, която е заделена за barsy
* При облачните инсталации - това зависи от използвания план.

Решение
----------

Пробвайте следните стъпки за оптимизиране на заявката:

 * изтегляйте само действително необходимите данни (нищо излишно, което не се ползва)
 * изтегляйте само на променените данни (има нарочни филтри, отразени в примерите, които демонстрират това)
 * намалете порциите изтегляна информация и теглете на няколко стъпки

Ако никое от горните стъпки не помага или имате по-специфичен проблем - свръжете се с поддръжката
