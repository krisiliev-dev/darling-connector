Искам да определя в кой търговски обект да се създаде сметка, но винаги отива в един и същи
==========================================================================================================


Въпрос:
--------
При подаване на заявка през Barsy API за създаване на `сметка </barsy.help/210-dictionary/account.html>`__ искам да посоча за кой `търговски обект </barsy.help/210-dictionary/barsy.html>`__ да е `сметката </barsy.help/210-dictionary/account.html>`__ - как мога да го направя ?

Отговор:
--------

Всеки рекуест към barsy API се изпълява в контекста на даден `търговски обект </barsy.help/210-dictionary/barsy.html>`__.
Когато не подавате инфорамция за такъв, системата автоматично определя такъв по подразбиране.

Можете да проверите кой е тeкущия `търговски обект </barsy.help/210-dictionary/barsy.html>`__ за вас със следния рекуест

| :doc:`/methods/barsys/getcurrent`

Всички налични `търговски обекти </barsy.help/210-dictionary/barsy.html>`__, до които имате достъп в конретната barsy система, можете да получите със следния рекуест

| :doc:`/methods/barsys/getlist`


За да подадете желан `търговски обект </barsy.help/210-dictionary/barsy.html>`__ за даден рекуест (при създаване на `сметка </barsy.help/210-dictionary/account.html>`__ на пример), трябва да подадете неговото ID (barsy_id)
като URL параметър към адрес, на който достъпвате конретната barsy система.

Пример:

   .. code-block:: none

      https://demo.barsyonline.com/endpoints/json/?bid=3
