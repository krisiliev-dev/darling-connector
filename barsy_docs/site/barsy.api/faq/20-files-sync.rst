Имам website - как да синхронизирам снимките на артикулите в него с barsy ?
============================================================================

Отговор
--------

За да изтеглите файловете, качени към `артикулите </barsy.help/210-dictionary/article.html>`__ от barsy можете да използате следните методи

  | :doc:`/methods/files/getlist`
  | :doc:`/methods/files/get`

Конкретни примери с различни реализации можете да намерите тук :doc:`/examples/files`


Допълнителен коментар
-----------------------
При повечето типове обекти (картинки) има заглавна картинка, чието име се връща заедно с останалите данни за обекта (примерно - за `артикул </barsy.help/210-dictionary/article.html>`__ -> PICTURE)
