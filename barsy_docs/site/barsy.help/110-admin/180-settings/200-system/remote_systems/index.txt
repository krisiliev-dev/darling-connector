 Oтдалечени системи 

 Отдалечените системи позволята система barsy да комуникира с други такива системи, като обменя информация и така спестява ръчна размяна на документи.

 Какво е отдалечена система?

 Отдалечените системи позволяват обмен на информация между две barsy системи, което спестява ръчната работа с файлове и документи.
