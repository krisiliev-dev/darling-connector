 Клиенти

 Клиенти 

 Конфигурациите в тази група са следните:

 Да не се проверява ДДС/ЕИК номер за валидност - При въвеждане на ДДС/ЕИК номер, системата да НЕ проверява неговата валидност и да не съобщава за некоректни стойности. Активира се чрез поставяне на отметка към етикет „Стойност“.

 MailChimp - API KEY - Конфигурацията служи за осъществяване на връзка между API средите на barsy и Mail Chimp.

 MailChimp - ID на списък с контакти - ListID на списъка с контакти, в който да бъдат импортнати клиентите. Отново във връзка с интеграция между MailChimp и barsy.

 Уникалност на клиент - Конфигурацията е от съществено значение по отношение на номенклатурата с клиенти в системата. От нея зависи как системата ще идентифицира уникалните потребители. Избора на елемент за уникалност се осъществява чрез падащото меню към етикет „Стойност“, като вариантите са: Телефон, E-mail, Име, Потребителско име.
