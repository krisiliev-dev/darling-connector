 Интеграция Common Provider и Barsy

 Настройване на плащане чрез Common Provider в Barsy

 Настройване на плащане чрез Common Provider в Barsy 

 Създаване на начин на плащане 

 Настройки >Основни >Начини на плащане >Нов начин на плащане

 Попълвате: 

 Име на начина на плащане (пример: Common Provider)

 Кратко име (пример: CProvider)

 Избирате ролите , които ще могат да използват този начин на плащане.

 Избирате външна система „Common Provider“.

 Запис.

 Настройване на начин на плащане за Common Provider 

 Настройки >Основни >Начини на плащане >Редактиране на начин на плащане (в случая: Common Provider)

 Основни данни >Външна система >Настройки: 

 Име на системата (пример: Common Provider)

 Api URL (от насрещната система - пример: https://api.common.provider/ )

 Api Username (от насрещната система - пример: user)

 Api Password (от насрещната система - пример: 123456789)

 Групиране (Избира се дали сметката да влиза в насрещната система групирана по ДДС ставка или ред по ред. По подразбиране: „По ДДС група“)

 Запис.

 Допълнителна информация при използване: 

 Заглавие (пример: Номер на стая)

 Валидация ( () )

 Източник на списък с данни Избирате „От външна система“ или „От външна система (с клиент и отстъпка)“.

 Note

 Без тази настройка системата ще покаже грешка при опит за плащане с Common Provider.
