 Google карти API ключ

 Google карти API ключ 

 За да ползвате Google карти в barsy e необходимо да предоставите API ключ.

 Взимане на Google карти API ключ 

 Моля следвайте стъпките от тук: https://developers.google.com/maps/documentation/javascript/get-api-key#quick-guide

 Вкарване на ключа в barsy 

 Отидете на Настройки » Системни » Конфигурация

 Натиснете бутон „Нова конфигурация“

 От списъка с възможни конфигурации изберете „Google карти API ключ“ в секция „Други“

 Въведете ключа в полето „Стойност“ и натиснете „Запиши“
