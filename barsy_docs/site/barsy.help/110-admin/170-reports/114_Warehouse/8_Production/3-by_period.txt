 2.5.4. Склад

 Производство

 По периоди

 По периоди 

 В тази справка се съдържа информация за броя извършени производства по периоди.

 Видима е следната информация по колони:

 Дата;

 Брой производства;

 Брой артикули (произведени);

 Сума себестойност без ДДС (сума среднопретеглена доставна цена без ДДС за периода);

 Филтри: 

 Период (дата от-до / касов период / конкретна дата);

 Артикул;

 Поток;

 Категории;

 Note

 Възможно е групиране на информацията по различни времеви интервали - седмица, месец, година и други. Настройва се от падащото меню до бутона „Филтри“.
