 2.7.3. Импорт в зареждане 

 За какво се ползва? 

 Импорт на артикули в ново или конкретно зареждане

 Как да стигна до него? 

 Склад->Зареждания-> „Ново зареждане“ или <някое зареждане> -> бутон „Импорт“

 Конфигуриране 

 Задължително е да бъде конфигурирана eдна от следните колони:
 Име на артикул

 ID на артикул

 Баркод

 Колони за конфигуриране 

 Артикул ID

 Разпознава артикула по ID (по номенклатурата на barsy).

 Действия при несъществуващ артикул - ако съществува дадения артикул какви да са действията на импорта

 Прескочи реда

 Прекрати импорта

 Име на артикул

 Разпознава артикула по име

 Действия при несъществуващ артикул - ако съществува дадения артикул какви да са действията на импорта

 Прескочи реда

 Прекрати импорта

 Баркод

 Разпознава артикула по баркод

 Действия при несъществуващ артикул - ако съществува дадения артикул какви да са действията на импорта

 Прескочи реда

 Прекрати импорта

 Количество

 Единична цена

 ДДС - процент ДДС

 Бележки

 Примерни файлове 

 Файловете представляват пример как можете да организирате своя входящ файл. Реда и броя на колоните не е задължителен. Точното значение на всяка колона можете да настроите в процеса на импортване на файла
