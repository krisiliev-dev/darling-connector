 Пресмятане на Марж и Надценка 

 Изчисляването на продажна цена БЕЗ ДДС се прави по формулата:

 Продажна цена / 1.2

 Пример: 10.00 / 1.2 = 8.52 евро

 Марж 

 Маржът показва печалбата като процент спрямо продажната цена.

 Изчислява се по формулата:

 ((Продажна цена без ДДС - Себестостойността) / Продажна цена без ДДС) * 100

 Надценка 

 Надценката показва печалбата като процент спрямо себестойността на артикула.

 Изчислява се по формулата:

 ((Продажна цена без ДДС / Себестойността) - 1) * 100
