Връзка към Barsy API
====================

Всички връзки към Barsy API се правя през HTTP 1.1. с GET или POST заявки. 

Заявките могат да бъдат формирани самостоятелно от външната система или да бъде използван помощния `клиент </barsy.help/210-dictionary/client.html>`__ :doc:`/usage/barsy_api_client`

Според конфигурацията на barsy системата, към която се прави връзка, може да се изпозва HTTP или HTTPS.

Подържаните формати за размяна на данни са:

Входящ (изпращане на данни към barsy API)
 * JSON (препоръчан)
 * Form-urlencoded
 * XML

Изходящ (получаване на данни от barsy API)
 * JSON (препоръчан)
 * HTML
 * CVS
 * XML
 * PDF
 * Excel
 * Excel XML
 * Plain
 * Custom

В един рекуест е възможно да бъдат комбинираните различни типове за входящ и изходящ формат.
Пример: входящите данните са изпратени като JSON, а изходящите са върнати като PDF
