Използване
==========================================

.. weight:: 20

Връзка с barsy API може да се осъществи по няколко начина:

   * чрез :doc:`/usage/barsy_api_client` - библиотека (PHP 8.1), даваща възможност да се изпълняват заявки към API като стандартни php функции
   * чрез :doc:`/usage/raw` - самостоятелно образуване на HTTP заявки към barsy API

За пълноценна връзка са необходими следните данни:
   * **хост** на насрещната система - пример mycoffee.barsy.bg
   * **потребител** за тази система
   * **парола** за използвания `потребител </barsy.help/210-dictionary/user.html>`__

`Потребителят </barsy.help/210-dictionary/user.html>`__ трябва да бъде създаден в самата система от друг `потребител </barsy.help/210-dictionary/user.html>`__, имащ право да създава нови такива.
