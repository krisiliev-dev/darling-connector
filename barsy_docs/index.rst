Barsy API документация!
==========================================

Този документ описва основните методи за комуникация между barsy и външна система. Връзката се осъществява през Barsy API и дава възможност да се получат 
всички данни, съхранявани в barsy, както и да се извършват всички действия, налични през административния модул.
